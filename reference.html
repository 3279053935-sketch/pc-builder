预算档位表

先选用途，再选预算。这里展示的是当前模板库里更有参考价值的档位；极限过渡档不放在这里，避免误导小白照抄。

主板和电源怎么省

这次按用户反馈调整：R5 5500 / R5 5600 这类 AM4 低中预算配置，不再默认把 B450M 升到 B550M。B550M 主要买扩展、PCIe 4.0 和更好供电，不是每套都刚需。

A520M极限省钱可用，适合 R5 5500 / R5 5600 低预算方案；扩展和供电别期待太高。
B450MAM4 性价比主力，R5 5600 搭它够用；下单看具体型号、BIOS 和售后。
B550M预算够、想要更好扩展/供电/PCIe4 再上，不再作为低预算默认升级项。

电源也不是只看瓦数。650W 主流卡够用，RX7700XT / RX9060XT 这类中端卡重点看具体型号和售后；RX7800XT / RX9070 / RTX4070Ti 往上建议优先看 750W 及以上。

先分清平台：AMD 主板看 Ryzen / R5，比如 A520M、B450M、B550M、A620M、B650M；Intel 主板看 i3 / i5 / i7，比如 H610M、B660M、B760M。不要拿 AMD CPU 去配 Intel 主板，也不要反过来。

显存怎么看

同一个显卡型号，显存容量会直接影响 3A、2K、材质包和部分生产力场景。页面里的显卡型号已经尽量补上 8G / 12G / 16G 等标注，但下单时仍要看商品标题。

8G 显存1080P 主流网游和轻 3A 可以用，但重 3A、2K、高材质要谨慎。
12G 显存1080P 更稳，部分 2K 也更舒服，是中端卡比较常见的安全线。
16G 及以上更适合 2K、重 3A、大材质包、剪辑设计和部分 AI/生产力需求。

生产力方向

生产力也不能只用一根条糊弄。这里按软件拆：它主要吃什么、低预算先补哪里、什么配置开始舒服。

PS / 平面修图

更吃单核响应、内存和 SSD。显卡有用，但普通修图不是越贵越好。

  • 入门可用：i3 / R5 5600G + 16GB + 512GB SSD
  • 舒服线：i5 / R5 5600 以上 + 32GB + 1TB SSD
  • 优先补：内存、SSD、CPU 响应

PR / 剪辑

吃 CPU、内存、硬盘容量，也吃显卡加速。素材越大，越不能只看显卡。

  • 1080P 轻剪：16GB 可起步，建议 1TB SSD
  • 4K / 多轨：32GB 起步，SSD 容量和速度都要看
  • 优先补：CPU、32GB 内存、1TB/2TB SSD、稳定电源

AE / 动效合成

很吃内存和缓存盘，预算不够时别急着把钱全塞给显卡。

  • 入门：32GB 内存比堆外观更有意义
  • 舒服线：强 CPU + 32GB/64GB + 高性能 SSD
  • 优先补：内存、缓存盘、CPU，多数情况再看显卡

Blender / 建模渲染

建模看 CPU/内存，GPU 渲染看显卡和显存。需求差异很大。

  • 只学建模：别一上来硬堆旗舰显卡
  • GPU 渲染：显存容量和 CUDA/驱动生态要重点看
  • 优先补：显卡显存、内存、CPU、稳定电源
剪辑设计预算紧时，先别急着买花哨机箱。内存、SSD、CPU 平台和电源稳定性更重要。显卡要看软件和素材类型，不是越贵越万能。

给朋友试用时怎么走

现在已经接近能拿出去试用。建议先按这个流程看，不要一上来就纠结所有细节。

1填真实预算不要故意写高，也不要把显示器预算混进去。
2看默认推荐先看系统推荐哪套，再对比省心/性能/省钱。
3开截图模式把三张卡片截图发给懂电脑的朋友。
4下单前复核价格、售后、具体型号、电源和主板别跳过。

三套方案应该怎么看

不要把三套方案理解成“从差到好”。它们是三种取舍：省心、性能、省钱。

稳妥全新版适合小白、怕售后麻烦、不想碰二手和奇怪搭配的人。
性价比版适合愿意压一点平台/外观预算，把钱更多花到性能上的人。
省钱够用版适合不想花满预算的人，不是最强，但目标是够用和少花钱。

同价替代和下单检查

这里不搬运别人的实测表，避免版权和出处问题。我们只保留选购逻辑：价格变了，应该往哪里替换。核心优先页支持自定义 CPU / 显卡型号和价格。

显卡替代 RX7800XT 涨价时，对比 RX9070GRE / RTX5060Ti 16G；RTX5060 太贵时，对比 RX6750XT / RX7600。不要只认一个型号。
平台替代 7000 元以上主流游戏单优先 AM5/DDR5；AM4 + 强显卡只作为省钱显卡版，不当主流推荐。
办公替代 高预算办公先补 CPU、内存、SSD、安静和售后，别为了花满预算硬塞游戏显卡。

装机别踩这几个坑

电源别瞎省

低预算也别拿杂牌电源赌。便宜可以，至少要看具体型号、售后和功率余量。

SSD 容量别太小

256GB/512GB 可以过渡，但游戏多、资料多的人迟早要加盘。

二手显卡要会验

不懂验卡就少碰高风险二手。真要买，看温度、噪音、接口、保修和退换。

预算不是非要花满

省钱版就是少花钱够用。预算多出来，如果没有明显升级点，可以先留着。
