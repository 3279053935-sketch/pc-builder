装机策略 · 先看用途，再看配件

装机之前，先搞懂钱该花在哪

这里不讲网站后台规则，专门给小白解释预算、主板、电源、显存和二手显卡这些最容易踩坑的地方。看懂这些，再回生成器选配置会轻松很多。

预算怎么分 主板怎么选 电源怎么看 显存怎么看 三种策略

预算先看用途，再决定钱花哪

不是所有电脑都应该把钱全堆到显卡，也不是所有电脑都该上贵 CPU。用途不同，预算重点也不同。

网游

CPU 和显卡都不能太偏。低预算纯网游，可以考虑 i3-14100F / i3-12100F + H610M 这种省钱路线。

3A 游戏

显卡优先级更高，但也不能让 CPU、内存和硬盘太拖后腿。画质和分辨率越高，显卡越重要。

办公 / 剪辑设计

办公更看 CPU、内存、硬盘体验；剪辑设计则要同时看 CPU、内存、SSD 和显卡，不是只看显卡。

主板怎么选：先分 AMD / Intel

主板是小白最难懂的硬件之一。先别管贵不贵，第一步先看你的 CPU 是 AMD 还是 Intel，再看 AM4 / AM5 或 H610 / B760 这些平台。

AMD CPU 看这一栏

常见 Ryzen 处理器会分 AM4 和 AM5，名字很像，但主板不是一回事。

R5 5500 / R5 5600：AM4 R5 7500F / R5 7600：AM5
A520MAM4 省钱板，适合 R5 5500 / R5 5600 低预算方案，够用但扩展一般。
B450MAM4 性价比常用选择，R5 5600 搭它很常见，下单要看具体型号、BIOS 和售后。
B550MAM4 更舒服，扩展和 PCIe 4.0 更好。预算够、显卡档位更高时再考虑，不是低预算必需品。
A620MAM5 入门省钱板，适合 R5 7500F / R5 7600 想压预算的新平台方案。
B650M / B850MAM5 主流选择，更适合新平台、后续升级、更多接口和更舒服的供电。

Intel CPU 看这一栏

Intel 主要看 CPU 代数和接口。低预算 i3 / i5 可以省，但高端 CPU 不要配太丐。

i3-12100F / i3-14100F i5-12400F / i5-13400F
H610MIntel 低预算够用板，适合 i3-12100F / i3-14100F / i5-12400F 这类不折腾升级的方案。
B660MIntel 主流选择，比 H610M 更舒服，适合 i5-12400F / i5-13400F 这类主流配置。
B760MIntel 近几年常见主流板，接口和扩展更好，适合预算够、想稳一点的 i5 方案。
Z 系列更偏高端和超频，不是小白低预算首选。除非 CPU 和用途真的需要，不然容易把钱花在看不见的地方。
小白先记住：AMD CPU 不能插 Intel 主板，Intel CPU 也不能插 AMD 主板。低预算别为了面子硬上贵板；高端配置也别用太丐的板。主板和电源要一起看，别一边说主板限制升级，一边又为了未来升级硬塞大瓦数电源。

电源不是瓦数越大越好

很多小白看到 650W / 750W 会觉得更高级，其实电源更重要的是型号、用料、保护、接口和售后。瓦数够用就行，别为了面子硬加。

低功耗网游机

整机不到 400W 的配置，550W 有售后型号通常够用。比如 i3 / R5 + 入门到中低端显卡，不必为了“未来升级”硬上 650W。

中端显卡

RX6750GRE、RX7700XT、RTX5060Ti、RX9060XT 这类，要结合整机功耗和电源具体型号看。550W / 650W 都可能合理。

高功耗显卡

RX7800XT、RX9070、RTX4070Ti 往上，再认真看 650W / 750W 甚至更高，同时主板也别太丐。

关键点：如果主板只是 A520 / B450 / H610 这种省钱平台，就别一边说“升级受限”，一边又为了未来升级硬塞大瓦数电源。

显存大不等于显卡强

8G、12G、16G 是显存容量，不代表显卡一定更强。小白最容易被“超大显存”这几个字带偏。

8G 显存

1080P 网游和部分轻 3A 可以用，但重 3A、2K、高材质要谨慎。RTX5050 / RTX5060 这类要看用途，不是只看新不新。

12G 显存

1080P 更稳，部分 2K 也更舒服，是中端卡比较常见的安全线。具体还要看核心性能。

16G 以上

更适合 2K、重 3A、大材质包、剪辑设计和部分 AI / 生产力需求。但同样 16G，也要看显卡本身强不强。

RTX5050 可以作为全新、低功耗、轻网游、低预算过渡方案，但不要拿它当性能性价比主推，更不要拿去主打 3A / 2K。

全新省心，二手看验卡能力

二手显卡确实可能更划算，但小白不会验卡时，风险也会跟着来。别为了省几百块，把售后和稳定性全赌进去。

全新显卡

贵一点，但售后清楚，更适合纯小白。预算够时，全新省心通常比极限性价比更重要。

熟人二手

如果来源靠谱、能看使用情况，比陌生平台更安心。但也要看温度、噪音、拆修和剩余保修。

平台二手

性价比可能高，但要会验卡。不会看成色、矿卡、维修、烤机和售后的人，不建议硬冲。

什么时候适合“核心硬件优先”？

适合

主要玩游戏；知道后面会加 SSD/内存；愿意复核电源和散热；不追求机箱外观。

不适合

完全小白；不想后续升级；对售后很敏感；办公/学习为主；需要稳定安静。
